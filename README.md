## About This Repository

This repository documents my SQL learning journey, with a primary focus on **Microsoft SQL Server** and its SQL dialect, **Transact-SQL (T-SQL)**.

It is designed to keep concepts, examples, and practice queries organised by topic. The roadmap starts with database concepts, moves through SQL fundamentals and querying, and then progresses to advanced programming, administration, performance optimisation, and practical database projects.

## Learning Objectives

- Understand database concepts, database models, and relational design.
- Learn SQL syntax, data types, operators, and constraints.
- Set up and work with Microsoft SQL Server and SQL Server Management Studio (SSMS).
- Create and manage database objects.
- Write SQL queries to retrieve, filter, sort, join, and analyse data.
- Use built-in SQL functions, grouping, and window functions.
- Understand transactions, database design, and normalisation.
- Learn T-SQL programming, database security, and administration.
- Improve query performance and apply SQL concepts through projects.
